# 自己紹介サイト・テンプレート（差し替えガイド）

「初めて自分を知る人」に渡すための自己紹介サイトのテンプレートです。
クライアント向けの実績アピールではなく、**人柄・考え方・好きなものが伝わること**を重視した構成です。
**素のHTML / CSS / JavaScript** だけでできており、ビルドやサーバーは不要です。

## 使い方
- `index.html` を**ダブルクリック**すればブラウザで表示できます。
- 中身は現在、東 レアンドロさんの実プロフィール（`プロフィール.txt`）と実写真をもとに作成済みです。
  内容を変えたい場合は下記の手順で書き換えてください。

## ファイル構成
```
portfolio/
  index.html   … 本文（ここの文章を書き換える）
  style.css    … 色・余白・デザイン（色を変えたいときはここ）
  script.js    … 動き（送信先メールはここ）
  assets/      … 画像（プロフィール写真・favicon）
  README.md    … この手引き
```

## ① 文章を差し替える（`index.html`）
`profile-info` の 01〜09 のメモを参考にしつつ、以下の対応で書き換えます。
（実績・サービス・お客様の声は前提が違うため、このテンプレには含めていません）

| セクション | 直す内容 |
|---|---|
| `<title>` / ヒーロー見出し・一言 | 名前、肩書き、自分を表す一言 |
| `自己紹介`（About） | 経歴・人柄が伝わる文章 |
| `大事にしている考え方`（4つの信条） | 仕事・生き方で大事にしていること |
| `好きなもの・興味があること`（5項目） | 趣味・好きなものを自分のものに差し替え（人柄が立体的に伝わる部分） |
| `お問い合わせ` | メール・Instagramのリンク |

※「できること」（スキルタグ）セクションは、具体的な使用言語・ツールの情報がなかったため削除しています。
スキルが定まったら、`大事にしている考え方` セクションと同じカード構造を参考に追加できます。

- 「好きなもの」は `<li class="likes-item">` を1ブロックとして増減できます。
- 「考え方」のうち大きく見せたい項目には `class="belief belief-lg"` を付けると、グリッド上で2倍幅になります（不要なら `belief-lg` を外すだけ）。

## ② 送信先メールを変える（`script.js`）
`script.js` の先頭付近：
```js
var CONTACT_EMAIL = "leandroayrtonazuma@gmail.com";  // ← 変更したい場合はここ
```
`index.html` の「Contact」内の `mailto:` と Instagram のURLも合わせて書き換えます。

## ③ 画像を差し替える（`assets/`）
- プロフィール写真：`profile-photo.jpg` を差し替え、`index.html` の `<img src="assets/profile-photo.jpg">` のファイル名を合わせます。
  - 現在は `style.css` の `.about-photo img` に `filter: grayscale(1) ...` を付けてモノトーン加工しています。カラーに戻したい場合はこの行を削除してください。
- favicon：`favicon.svg` を好みのロゴ・イニシャルに変更。

## ④ 色を変える（`style.css`）
`style.css` の冒頭 `:root { … }` の変数だけ変えれば全体の色が変わります。
このテンプレは**クリーム × ディープブラックの2色だけ**に絞っているのが特徴です。
```css
--bg: #F4F1EA;   /* クリーム（地） */
--ink: #1A1A1A;  /* ディープブラック（文字・インク） */
```
色を増やすと量産テンプレ感が出やすいので、基本はこの2色のままで濃淡・罫線だけで階調をつけることを推奨します。

## ⑤ 「サービス」「お客様の声」「実績」を後で追加したい場合
このテンプレには含まれていません。仕事の依頼用途も兼ねたくなった場合は、
`大事にしている考え方` セクション（`.beliefs-list` / `.belief`）と同じ構造をコピーして、
カード形式のセクションとして追加するのがこのデザインに馴染みやすい方法です。

## 公開する場合（任意）
- **GitHub Pages**：リポジトリに3ファイル＋assetsを置き、Pagesを有効化するだけで公開できます。
- **Netlify / Vercel**：フォルダをドラッグ＆ドロップでも公開可能。
